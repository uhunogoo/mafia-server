# 14 — CONTEXT.md initial glossary

Type: task
Status: open
Blocked by: 03, 11

## Question

Створити `CONTEXT.md` у корені репозиторію з початковим глосарієм термінів Mafia-гри (з урахуванням прийнятих рішень з мапи).

Потрібно:

1. **Структура файлу** відповідає `docs/agents/domain.md`:
   - Канонічні терміни з чіткими визначеннями
   - Без implementation details (тільки domain vocabulary)

2. **Терміни для внесення** (з регламенту + прийнятих рішень):
   - **Гравець (Player)**: сутність у кімнаті, має sessionId, name, seatIndex, role (приватно)
   - **Ведучий (Host)**: Player з `isHost=true`. Не отримує роль, не голосує, керує глобальними фазами та записує дії
   - **Стіл (Table)**: синонім «кімнати» (room), але в термінах гри — місце, де сидять гравці та ведучий
   - **Фаза (Phase)**: поточний стан гри (`GamePhase`)
   - **Нічна фаза (Night Phase)**: `NIGHT_MAFIA`, `NIGHT_DON_CHECK`, `NIGHT_SHERIFF_CHECK`, `NIGHT_DOCTOR_HEAL`
   - **Денна фаза (Day Phase)**: `DAY_ANNOUNCE`, `DAY_BALAGAN`, `DAY_SPEECHES`, `DAY_DEFENSE`, `DAY_VOTE`, `DAY_REVOTE`
   - **Роль (Role)**: CIVILIAN, SHERIFF, DOCTOR, MAFIA, DON
   - **Команда (Team)**: RED, BLACK
   - **Номінація (Nomination)**: виставлення гравця кандидатом на голосування. Доступна лише під час своєї промови
   - **Промова (Speech)**: 1-хвилинний монолог гравця. Порядок — round-robin від seat #1
   - **Захист (Defense)**: 30-секундне фінальне слово кандидата
   - **Голосування (Vote)**: host-mediated підрахунок. Утримались → голосують за останнього в черзі
   - **Перевірка (Check)**: нічна дія дона (на шерифа) або шерифа (на колір)
   - **Лікування (Heal)**: нічна дія лікаря (рятує ціль мафії)
   - **Тестова ніч (Test Night)**: Night 1 — мафія знайомиться, не вбиває
   - **Жест (Ping)**: визначена коротка фразa-чіп, що замінює фізичний жест
   - **Видимість пінгу (Ping Visibility)**: визначається контекстом (ніч vs день), а не текстом чіпа
   - **Одне активне питання (One Active Question)**: обмеження — поки на гравці висить чуже питання, він не може ставити нові
   - **Таймаут пінгу (Ping Timeout)**: 15-20с. Якщо адресат не відповів — бейдж зникає
   - **Мертва тиша (Dead Silence)**: мертві втрачають пінги
   - **Auto-pardon**: tie у revote → ніхто не вибуває, ніч
   - **Лог ролі (Role Log)**: per-role буфер дій (`mafiaLog`, `donLog`, `sheriffLog`, `doctorLog`)
   - **Host log**: синонім — ведучий бачить усі role logs

3. **Уникати**:
   - Не використовувати «account», «user» — це Player
   - Не використовувати «cancel» — це «resolved» / «pardoned»
   - Не використовувати «chat» — це Ping

Відповідь — це готовий файл `CONTEXT.md` (створити директору якщо потрібно — корінь репо).

## Out of scope
